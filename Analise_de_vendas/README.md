# 📊 O programa Analise de Vendas.

> Projeto desenvolvido durante os estudos de fundamentos de programação em Java, reunindo diferentes conceitos trabalhados no curso de Ciência da Computação.

---

## 📌 Sobre o projeto

O programa utiliza dados fictícios de vendas de uma lanchonete para organizar e processar a quantidade de produtos vendidos ao longo dos dias da semana.

A partir desses dados, o programa:

- 📅 Organiza os registros de vendas por dia;
- 📦 Trabalha com diferentes produtos;
- 📊 Processa os dados utilizando matrizes;
- ➕ Calcula o total de produtos vendidos por dia;
- 🧮 Calcula o total de vendas por produto;
- 📈 Calcula a média diária de vendas;
- 🖥️ Exibe os resultados de forma organizada no console.

---

---

## ⚙️ Funcionamento

O programa possui diferentes métodos, cada um responsável por uma parte do processamento.

### `main()`

Responsável por armazenar os dados iniciais e iniciar a execução do programa.

### `matrizRegular()`

Cria uma matriz regular a partir dos dados inicialmente armazenados em uma matriz com linhas de tamanhos diferentes.

### `vendasPorDia()`

Calcula a quantidade total de produtos vendidos em cada dia.

### `vendasDeProdutos()`

Calcula a quantidade total de cada produto vendido durante a semana.

### `imprimirTabela()`

Organiza e apresenta os dados processados no console.

### `maiorDia()`

Identifica o maior nome entre os dias da semana para auxiliar na formatação da tabela.
